# MoviewWatchlist

MovieWatchlist merupakan aplikasi yang digunakan untuk mencatat film yang telah kita tonton. Pengguna dapat menyimpan informasi film, memberikan rating, mengunggah poster film dan menambahkan ulasan singkat tentang film yang telah di tonton sebagai dokumentasi pengalaman menonton.
